# REST API

The full OpenAPI 3 spec is auto-generated by FastAPI and served live at
`/api/docs` (Swagger UI) and `/api/openapi.json` (raw schema) on a running
stack. This page is a stable summary of the v1 surface.

All state-changing requests (`POST`, `DELETE`) require the double-submit CSRF
header `X-Prism-Csrf` echoing the `prism_csrf` cookie set at login — see
{doc}`../how-to/upload-raw-http`.

## Auth

| Method & path | Purpose |
|---|---|
| `POST /api/v1/auth/login` | Set session + CSRF cookies |
| `POST /api/v1/auth/logout` | Clear cookies |
| `GET /api/v1/auth/me` | Current user |

## Users

| Method & path | Purpose |
|---|---|
| `GET /api/v1/users` | List |
| `POST /api/v1/users` | Create (any authenticated user) |
| `DELETE /api/v1/users/{id}` | Delete (blocked for self / last user) |

## Projects

| Method & path | Purpose |
|---|---|
| `GET /api/v1/projects` | List |
| `POST /api/v1/projects` | Create |
| `GET /api/v1/projects/{slug}` | Detail |

## Runs

| Method & path | Purpose |
|---|---|
| `GET /api/v1/runs?project=&status=&limit=` | Paginated list |
| `POST /api/v1/runs` | Multipart upload (CSRF-protected) |
| `GET /api/v1/runs/{id}` | Detail with suites |
| `GET /api/v1/runs/{id}/report.pdf` | Per-run compliance PDF |

## Suites & cases

| Method & path | Purpose |
|---|---|
| `GET /api/v1/suites/{id}/cases` | Cases under a suite |
| `GET /api/v1/cases/{id}` | Case detail incl. attached artifacts and measurements |

## Artifacts

| Method & path | Purpose |
|---|---|
| `GET /api/v1/artifacts/{id}` | Metadata |
| `GET /api/v1/artifacts/{id}/download` | 307 redirect to a signed MinIO URL |
| `GET /api/v1/artifacts/{id}/waveform?downsample=N` | JSON time-domain samples |
| `GET /api/v1/artifacts/{id}/fft?window=hann&nfft=1024&overlap=0.5` | JSON spectrum (cached) |

## Compare

| Method & path | Purpose |
|---|---|
| `POST /api/v1/compare` | Body `{run_ids: [a, b, …]}` (CSRF-protected) |
